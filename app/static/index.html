AI Intake Notifier (automatic on every patient message)

As soon as a patient message arrives, intake-only analysis runs automatically in the dashboard and the follow-up question is pushed to the patient's phone via the same WhatsApp channel the doctor uses — one per message, one at a time, never duplicated. Resolved sugar values are stored into the readings table automatically and the food the patient described is logged into the meal record with the message timestamp (ambiguous readings like "230 or 330" wait for the patient). It only asks for missing logging details (reading value, fasting/post-meal tag, meal items, portion) in short Hinglish — it is not a doctor and never gives medical advice.
